## 🚀 Install & Running

#### 1. Run server

```sh
# install server
git clone git@github.com:dusixx/async-race-api.git
cd async-race-api
npm i

# run server
npm start
```

**⚠️ NOTE:** The default port is 3000. Don't change it -- frontend deployment is tied to it!

#### 2. Run client

Run [deploy](https://async-racex.netlify.app/)
