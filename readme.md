## 🚀 Install & Running

#### 1. Install server

```sh
git clone git@github.com:dusixx/async-race-api.git
cd async-race-api
npm i
```

#### 2. Run server

**NOTE:** The default port is **3000**. Don't change it -- frontend deployment is tied to it!

```sh
npm start
```

#### 3. Run client

👉 [deploy](https://async-racex.netlify.app/)
